# Customer Intelligence Platform

An end-to-end customer intelligence and segmentation platform that transforms 540K+ raw e-commerce transactions into high-precision commercial segments using supervised machine learning and K-Means clustering. Features automated data ingestion from the UCI Machine Learning Repository, leakage-free feature engineering, cross-validated classification models, financial Customer Lifetime Value (CLV) estimations, and a real-time Streamlit executive dashboard.

---

## 1. Problem Statement

Retail businesses frequently hemorrhage marketing capital by blasting uniform discount vouchers to their entire customer database—subsidizing loyal buyers who would pay full price, while overlooking disengaging high-value spenders until they have permanently defected to competitors. In our analyzed retail transaction base, **less than 23% of customer accounts generate more than 73% of total enterprise revenue**, with top at-risk accounts representing hundreds of thousands of pounds in vulnerable revenue. The **Customer Intelligence Platform** solves this by converting raw invoice histories into predictive behavioral vectors, identifying exactly which customers are high-value, habitual, or churning, and clustering them into actionable commercial groups with customized retention playbooks.

## 5. How to Run

### Step 1: Install Dependencies
Ensure Python 3.10+ is installed. Clone the repository and install dependencies:
```bash
pip install -r requirements.txt
```

### Step 2: Execute the Training Pipeline
Run the full end-to-end pipeline. This automatically fetches the dataset from UCI, runs data hygiene checks, engineers 11 features, performs 5-fold cross-validation, trains classifiers, runs K-Means clustering, computes CLV reports, and seeds the live streaming feed:
```bash
python train.py
```
*(Execution time: ~35–40 seconds)*

### Step 3: Launch the Executive Dashboard
Start the Streamlit application to explore interactive KPIs, segment profiles, and live auto-refreshing transaction streams:
```bash
streamlit run dashboard/app.py
```

To simulate incoming daily transactions in real time, open a separate terminal window and run:
```bash
python src/simulate_live.py --days 1
```
The Streamlit dashboard will automatically pick up the new records during its 30-second refresh cycle without requiring a server reboot.

## 6. Limitations & Analytical Boundaries

Before deploying this platform in commercial environments, stakeholders should review our documented constraints in [**docs/LIMITATIONS.md**](docs/LIMITATIONS.md), specifically:
* The absence of promotional campaign metadata and marketing channel attribution.
* Cold-start classification uncertainty for one-time buyers (~35% of accounts).
* The deterministic nature of the simplified Customer Lifetime Value formula.
* The necessity of controlled A/B testing before scaling intervention recommendations.
